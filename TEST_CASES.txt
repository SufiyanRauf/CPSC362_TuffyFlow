Clock formatting (7 cases)
--------------------------

time.ts turns a stored time into something a student reads, and six screens go through
it, so one broken branch here is wrong on all six at once. The two event screens format
their own dates with Intl directly and are covered by Event dating instead.

Covers: The screens that read a stored time through src/lib/time.ts.
File: tests/clock_text.test.mjs
Command: npm run test:dates

ID:              CLK-01
What it checks:  clockText prints midnight and noon as 12, not 0
Expected result: assert.equal(clockText('00:00'), '12:00 AM');
                 assert.equal(clockText('00:15'), '12:15 AM');
                 assert.equal(clockText('09:00'), '9:00 AM');
                 assert.equal(clockText('11:59'), '11:59 AM') (8 assertions in all)
Result:          Pass

ID:              CLK-02
What it checks:  clockText drops the seconds the database stores
Expected result: assert.equal(clockText('09:00:00'), '9:00 AM');
                 assert.equal(clockText('12:45:00'), '12:45 PM')
Result:          Pass

ID:              CLK-03
What it checks:  clockText hands back anything that is not a time
Expected result: assert.equal(clockText('now'), 'now'); assert.equal(clockText(''), '')
Result:          Pass

ID:              CLK-04
What it checks:  clockRange says the meridiem once when both ends share it
Expected result: assert.equal(clockRange('09:00:00', '10:15:00'), '9:00\u201310:15 AM');
                 assert.equal(clockRange('14:00:00', '15:15:00'), '2:00\u20133:15 PM')
Result:          Pass

ID:              CLK-05
What it checks:  clockRange keeps both when the range crosses noon or midnight
Expected result: assert.equal(clockRange('11:30:00', '12:45:00'), '11:30 AM\u201312:45
                 PM'); assert.equal(clockRange('23:00:00', '00:30:00'), '11:00
                 PM\u201312:30 AM')
Result:          Pass

ID:              CLK-06
What it checks:  toMinutes counts from midnight
Expected result: assert.equal(toMinutes('09:30'), 570);
                 assert.equal(toMinutes('11:30:00'), 690);
                 assert.equal(toMinutes('00:00'), 0)
Result:          Pass

ID:              CLK-07
What it checks:  clockRange hands back values that are not times
Expected result: assert.equal(clockRange('TBA', 'TBA'), 'TBA\u2013TBA');
                 assert.equal(clockRange('', ''), '\u2013');
                 assert.equal(clockRange('now', 'now'), 'now\u2013now')
Result:          Pass
